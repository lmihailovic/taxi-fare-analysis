# Apache Spark

1. Дати сортирано парове локацијa вожњи (вожња је од локације до локације, тј.
од једног краја/Зоне града до другог) са највећом просечном ценом (сортирати
опадајуће). 
  
   Овај задатак је потребно реализовати преко **RDD** колекције и **map-reduce** метода.

   Формат резултата:  
   `((PULocationID, DOLocationID), Prosečna Cena Vožnje)`


2. Из којег дела града (Zone) путници најчешће путују на аеродром? (пажња –
постоје три аеродрома - JFK, LaGuardia, Newark)
   
   Формат резултата:

```
+------------+---------+---------------+
| Zone       |  Borough|  Ukupno Vožnji|
+------------+---------+---------------+
```
3. За сваки дан, пронаћи зону из које су започете вожње са највећом просечном
дистанцом.

   Формат резултата:

```
+---------+-------------+----------+----------------------+
|     Zone|      Borough|     Datum|Prosečna Dužina Vožnje|
+---------+-------------+----------+----------------------+
```


4. У којем крају је најбоље таксирати (највише има муштерија) у периоду од 9:00h-
11:59h, ако је таксистима одлучујући параметар просечна дужина временске
паузе између два поласка из тог краја (Zone).

   Формат резултата:
```
+---------------+---------+------------------+
|           Zone|  Borough|Prosečna Pauza Sec|
+---------------+---------+------------------+
```

Функције за рад са timestampom су: `to_date()` – враћа датум из timestamp вредности,
`hour()` - враћа сат из timestamp-a, `unix_timestamp()` - враћа укупан број секунди из
timestamp-a почевши од 1. јануара 1970.
